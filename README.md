- **Deterministic Sub-15ms NLP Pipeline:** Multi-stage computational linguistics parsing unconstrained natural language without external cloud API dependencies.
- **Clinical NegEx Negation Analysis:** Accurately isolates denied symptoms (e.g. *"headache but no cough or fever"*) using forward token windows and clinical trailing markers.
- **Hands-Free Speech Dictation:** Integrated native Web Speech API recognition with real-time token deduplication for clinical queries.
- **Life-Threatening Red-Flag Interception:** Immediate priority triage intercepting acute cardiac, respiratory, and neurological emergencies.
- **Interactive Tour & Sandbox (`/demo`):** Built-in guided walkthrough with one-click test presets for rapid evaluation.
